# D8_Weaponry
A mod that add it own ammo system and renderer with a bunch of weapons craftable at a Gunsmith Table!
It currently add :

- 1 new ranged weapon kind : Physical/External Ammo Using Weapon
- 1 new crafting station   : Gunsmith Table, allow to craft weapon and munition
- 1 new upgrade station    : Refinement Workbench, allow to upgrade 'almost' any weapon's
- 6 unique weapon

#### Developement Philosophy
- The current developement phylosophy is

  - keep the strengh based around vanilla scaling
